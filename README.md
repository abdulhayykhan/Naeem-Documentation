# Naeem Documentation Website

<img src="media/logo.png" alt="Naeem Documentation Logo" width="200" />

A modern, high-performance, and mobile-first static website designed for **Naeem Documentation**, a printing and legal documentation service provider in Karachi, Pakistan.

This repository contains the complete source code for the landing page, featuring a polished "Glassmorphism" aesthetic, interactive service menus, and direct WhatsApp integration.

## 🚀 Features

* **Mobile-First Design:** Fully responsive layout that looks perfect on smartphones, tablets, and desktops.
* **Direct WhatsApp Integration:**
    * **"Get a Quote"** buttons with pre-filled messages.
    * **"Inquire"** buttons for specific services (e.g., clicking "Inkjet Print" opens WhatsApp with *"Hello, can you tell me more about your Inkjet Print?"*).
    * Sticky WhatsApp floating button on mobile.
* **Interactive UI Elements:**
    * **Live Ticker:** Scrolling updates bar for news and offers.
    * **Service Accordions:** Expandable lists for Printing, Legal, Identity, and Finishing services to keep the UI clean.
    * **Animated Counters:** "Customers Served" and "Impressions Printed" numbers count up when scrolled into view.
* **Modern Aesthetic:** Uses a deep navy and gold color palette with glass-effect (frosted blur) overlays.
* **Performance:** Lightweight static HTML/CSS with no heavy backend dependencies.

## 🛠️ Tech Stack

* **HTML5:** Semantic markup.
* **Tailwind CSS (CDN):** Utility-first CSS framework for rapid styling and responsiveness.
* **JavaScript (Vanilla):** Handles the accordion logic, counter animations, and mobile menu toggling.
* **Heroicons:** SVG icons for the service sections.
* **Google Fonts:** Uses the "Manrope" font family for a clean, professional look.
